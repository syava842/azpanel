# Журнал изменений

## Текущие изменения

### Интерфейс
- Раздел WARP — родная веб-панель AZ-WARP во встроенном окне вместо своей
  сводки, доменов и подсетей. azpanel отдаёт её под своим адресом
  `/warp/ui/` только администраторам. Не установлен AZ-WARP — форма установки
  там же, вместе с веб-панелью; нет только веб-панели — форма её установки.
- Форма установки AZ-WARP повторяет вопросы и умолчания его установщика:
  источник ключей WARP, WireGuard-конфиг и .ovpn выбираются из найденного на
  сервере, рекомендуемый MTU показан, поля видны только для выбранного выхода;
  у веб-панели — порты, HTTPS (по умолчанию выключен), домен и режим
  публикации. Домены Gemini и ChatGPT по умолчанию не добавляются.
- Встроенное окно WARP работает и с веб-панелью без nginx (gunicorn на
  внешнем порту, в том числе с HTTPS).
- Главная страница: время работы, процессор, память, диск; плитки OpenVPN и
  WireGuard — онлайн, заблокированные, истекающие сертификаты; службы
  AntiZapret одной строкой с раскрытием; графики истории. Страница «Сейчас»
  влилась в главную, старый адрес `/monitor` ведёт на неё.
- «Обновление AZ» под setup.sh AntiZapret от 26.11.2026 (b988532): три новых
  вопроса вводом после списков IP — адрес входа/выхода (DEFAULT_IP) и адреса
  выхода режимов AntiZapret и полного VPN (ANTIZAPRET_OUT_IP, VPN_OUT_IP);
  берутся из setup узла, пусто — определение автоматическое. Адрес WARP теперь
  «адрес:порт».
- Синхронизация серверов не переносит на реплику ключи, привязанные к самому
  серверу: DEFAULT_IP, ANTIZAPRET_OUT_IP, VPN_OUT_IP и соответствующие
  *_INTERFACE — у реплики остаются свои.
- «Обновление AZ» под setup.sh AntiZapret от 17.11.2026: новые вопросы
  (адрес WARP, защита от флуда, переподключение WARP, сброс кэша DNS, чистка
  спам-доменов), меню DNS из шести пунктов (GeoHide: 7 → 6). Сверка
  setup.sh теперь проверяет и вопросы, которые читают ввод всегда: новый такой
  вопрос сдвинул бы ответы — теперь это отказ запуска, а не сдвиг.
- Разделы OpenVPN и WireGuard по образцу StatusOpenVPN. **Сеансы**: реальный
  IP, IP в VPN, получено и отправлено со скоростью, подключён, длительность,
  протокол и порт, AntiZapret или VPN, итог, сортировка по столбцам,
  «Показать IP», переключатель автообновления, время в часовом поясе
  браузера. Новая вкладка **История** — подключения с фильтром и страницами
  (хранится history_days). **Статистика** — сутки, неделя, месяц, год или
  свои даты, график по дням, все клиенты раздела, доля, сортировка; трафик
  по суткам хранится 400 дней.
- `azpanel user add --help` заводил пользователя «--help»: логин не может
  начинаться с «-» или «.», такой аргумент — ошибка вызова.
- Клиенты без сертификата на сервере: OpenVPN пускает их (CA тот же), а в
  `pki/issued` их нет — index.txt неполный. Теперь они в списке по живому
  сеансу и по блокировке, с пометкой «сертификата нет на сервере»; продление,
  удаление и профиль у них скрыты, лимит и блокировка работают.
- Удаление клиента и пользователя: имя для подтверждения написано рядом с
  полем и подставлено подсказкой. После удаления клиента — обратно туда,
  откуда пришли на его страницу (список, раздел OpenVPN или WireGuard,
  страница пользователя), иначе список клиентов этого вида.
- Разделы OpenVPN и WireGuard с вкладками «Сеансы», «Клиенты» и «Статистика»
  (трафик клиентов за 1, 7, 30 дней). Пункт WireGuard в меню — только если у
  сервера есть его клиенты. Общий список всех клиентов — по адресу `/clients`.
- Автообновляемые страницы (задача, главная, сеансы, обновления) больше не сбрасывают
  прокрутку: страница и журнал остаются на месте; журнал, прокрученный до
  конца, продолжает показывать новые строки; при открытии — с конца.

### Мастер установки
- azpanel открывается либо по порту — свой сайт, `https://<хост>:5000/`
  (порт по умолчанию 5000), — либо по пути — разделом `/azpanel/` вашего
  сайта nginx; вместе не бывает. По пути мастер перечисляет подходящие сайты
  с точным адресом и даёт выбрать; подходящего нет — по пути не предлагает.
  При смене способа прежний раздел или свой сайт убирается. По умолчанию —
  по порту.
- Вопросы: домен, HTTPS, как открывать (по порту — и порт), логин и пароль. Тип установки, внешний IP,
  выбор server-блока, вид сертификата, почта, бэкапы, файрвол и смена пароля
  больше не спрашиваются — решаются сами и видны в итоге.
- Без HTTPS: раздел в сайте nginx без ssl или свой сайт без ssl.
- Домен, указывающий на другой сервер, и занятый порт не принимаются.
- Let's Encrypt без почты; предупреждение, если сертификат сайта истёк или
  выписан на домен, а открывать будут по IP.
- Узел для панели на другом сервере (`AZPANEL_MODE=node`) по ключу из
  панели: команда, которую показывает панель, теперь работает (переменные
  окружения и setup.sh вместо неверных аргументов). Мастер проверяет ключ
  (`AZPANEL_NODE_KEY` или `AZPANEL_NODE_KEY_FILE`; без него спрашивает),
  пишет токен в `secrets.env`, включает TLS-порт `0.0.0.0:9100` с белым
  списком из адреса панели, уводит петлевой API на `127.0.0.1:9102` и
  печатает отпечаток сертификата агента и порт, который открыть. Подсказка
  «0.0.0.0:9100» в «Настройках» больше не ведёт к конфликту портов.

### Каталог установки
- azpanel ставится в `/root/azpanel`, рядом с `/root/antizapret`. Прежние
  установки из `/opt/azpanel` продолжают работать и переносятся командой
  `azpanel relocate` (её же вызывает `update.sh`); при сбое перенос
  возвращает всё на место.
- Хук OpenVPN работает не от root, поэтому вызывает копию программы в
  `/usr/local/lib/azpanel`; агент обновляет её при каждом запуске.
- Службе панели из `/root` виден только каталог azpanel.

### Внешний адрес панели
- Мастер ставит `panel.public_url` по одному правилу: задан домен — он, не
  задан — внешний IP сервера; имя сайта из nginx больше не подставляется, и
  для пути в nginx домен не обязателен.
- Предупреждение, если заданный домен указывает на другой сервер.

### Консоль, бэкапы, вход
- Меню `azpanel` (без аргументов в терминале, `azpanel menu`, `admin.sh`):
  состояние, пользователи, смена пароля, новый администратор, обновление,
  перезапуск служб.
- `azpanel user passwd <логин> [--generate]`, `azpanel user add … --password`:
  пароль свой или сгенерированный.
- Бэкапы по подкаталогам: `backup/azpanel`, `antizapret/archives`,
  `antizapret/lists`, `nginx`;
  прежние файлы переезжают сами при запуске агента.
- Форма входа: поля `username` и `password` с `id` — браузер предлагает
  сохранить логин и пароль; в форме смены пароля — скрытый логин.

### Интерфейс и документация
- Новый интерфейс: меню слева по разделам, светлая и тёмная тема, версия для
  телефона; страница клиента в две колонки.
- `azpanel user add <логин> [--admin]` — добавить пользователя из консоли.
- Самообновление и проверка обновлений работают без токена GitHub.
- README по образцу StatusOpenVPN, `docs/install.md` — подробно об
  установке, `docs/interface.md` — что делают страницы.

### Установка одной командой
- `scripts/setup.sh`: последний релиз под архитектуру, проверка подписи
  ed25519 и суммы, мастер `azpanel install`. Нет AntiZapret-VPN — предлагает
  поставить его родным установщиком.
- `scripts/update.sh`, `uninstall.sh`, `change_passwd.sh` — обёртки над
  командами azpanel.
- Ссылка `/usr/local/bin/azpanel`: ставится установкой, снимается удалением.
- `azpanel update` работает без токена GitHub (репозиторий публичный).
- Ключ релизов задан; архивы релиза с правами 0755.
