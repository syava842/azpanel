# Журнал изменений

## Текущие изменения

### Интерфейс и документация
- Новый интерфейс: меню слева по разделам, светлая и тёмная тема, версия для
  телефона; страница клиента в две колонки.
- `azpanel user add <логин> [--admin]` — добавить пользователя из консоли.
- Самообновление и проверка обновлений работают без токена GitHub.
- README по образцу StatusOpenVPN, `docs/install.md` — подробно об
  установке, `docs/interface.md` — что делают страницы.

### Установка одной командой
- `scripts/setup.sh`: последний релиз под архитектуру, проверка подписи
  ed25519 и суммы, мастер `azpanel install`. Нет AntiZapret-VPN — предлагает
  поставить его родным установщиком.
- `scripts/update.sh`, `uninstall.sh`, `change_passwd.sh` — обёртки над
  командами azpanel.
- Ссылка `/usr/local/bin/azpanel`: ставится установкой, снимается удалением.
- `azpanel update` работает без токена GitHub (репозиторий публичный).
- Ключ релизов задан; архивы релиза с правами 0755.

### Этап 2а
- Панель: вход, роли, клиенты, маршрутизация, первичная настройка.
- Хранилище: unlock-коды, ссылки портала, очередь уведомлений.
- Клиент Telegram Bot API.

### Этап 2в
- Релизы: сборка, `SHA256SUMS` и подпись ed25519 (`scripts/release.sh`,
  `azpanel-sign`).
- Проверка подписи обновления (`internal/update`).
