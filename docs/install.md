# Установка azpanel подробно

[← К README](../README.md) · [Веб-интерфейс](interface.md)

## Что делает установщик

Команда `setup.sh`:

1. Проверяет root, Linux, процессор amd64 или arm64.
2. Проверяет, что AntiZapret-VPN установлен (`/root/antizapret/client.sh`).
   Если нет, предлагает:
   1. поставить его родным установщиком
      [GubernievS/AntiZapret-VPN](https://github.com/GubernievS/AntiZapret-VPN) —
      он в конце перезагружает сервер, после этого команду нужно запустить
      ещё раз;
   2. продолжить без него — только агент прокси;
   3. выйти.
3. Скачивает последний релиз под процессор сервера, проверяет подпись
   ed25519 и контрольную сумму. Не сошлось — установка останавливается.
4. Запускает мастер `azpanel install`.

Если azpanel уже установлен, скрипт ничего не меняет и подсказывает команду
обновления.

## Вопросы мастера

Enter оставляет значение в скобках. Перед изменениями мастер показывает итог
и ждёт подтверждения; до него ничего не меняется.

Внешний IP сервера мастер определяет сам (спрашивает, только если не
удалось). Затем пять вопросов:

| № | Вопрос | Что значит |
| --- | --- | --- |
| 1 | Порт azpanel [8443] | порт, если открывать по порту; занятый не принимается |
| 2 | Домен | пусто — по IP; домен, который указывает на другой сервер, не принимается |
| 3 | Включить HTTPS [Y/n] | без HTTPS логин и пароль идут открытым текстом |
| 4 | Как открывать azpanel | **по имени** — разделом `/azpanel/` вашего сайта в nginx, а если сайта нет — своим сайтом на 443 (80 без HTTPS) · **по порту** — своим адресом на порту из вопроса 1, ваши сайты в nginx не трогаются |
| 5 | Администратор | логин и пароль; Enter — сгенерировать (тогда при первом входе попросит сменить) |

Остальное мастер решает сам и показывает в итоге: сертификат (см. [Домен и
HTTPS](#домен-и-https)), бэкапы AntiZapret раз в день с 14 копиями (меняется
в «Настройках»), какие порты открыть. Ответы сохраняются в `install.env` и при
переустановке подставляются сами.

После установки azpanel доступна:

| Как открывать | Адрес |
| --- | --- |
| по имени | `https://<домен или IP>/azpanel/` |
| по порту | `https://<домен или IP>:8443/` |
| только 127.0.0.1 (`AZPANEL_ACCESS=local`) | через SSH-туннель, см. [FAQ](#faq) |

Проверка: `azpanel doctor`.

## Установка без вопросов

Ответы задаются переменными `AZPANEL_*`; не заданные берутся по умолчанию
(по имени, HTTPS, по IP, логин `admin`, пароль сгенерировать).

```bash
AZPANEL_DOMAIN=vpn.example.com AZPANEL_ADMIN=admin AZPANEL_ADMIN_PASSWORD='пароль' \
  bash -c "$(curl -fsSL https://raw.githubusercontent.com/syava842/azpanel/main/scripts/setup.sh)" -- --non-interactive
```

| Переменная | Значения |
| --- | --- |
| `AZPANEL_PORT` | порт для открытия по порту (по умолчанию 8443) |
| `AZPANEL_DOMAIN`, `AZPANEL_ADDRESS` | домен, внешний IP |
| `AZPANEL_HTTPS` | `y` (по умолчанию) или `n` |
| `AZPANEL_ACCESS` | `path` — по имени (по умолчанию), `port` — по порту, `local` — только 127.0.0.1 |
| `AZPANEL_TLS=own`, `AZPANEL_CERT`, `AZPANEL_KEY` | свой сертификат вместо выбранного мастером |
| `AZPANEL_EMAIL` | почта для Let's Encrypt (необязательна) |
| `AZPANEL_MODE` | `panel+node` (по умолчанию); остальные — для нескольких серверов |
| `AZPANEL_ADMIN`, `AZPANEL_ADMIN_PASSWORD` | логин и пароль администратора |
| `AZPANEL_BACKUP_DIR`, `AZPANEL_BACKUP_DAYS`, `AZPANEL_BACKUP_KEEP` | бэкапы |
| `AZPANEL_SKIP_ANTIZAPRET=1` | не спрашивать про AntiZapret (сервер прокси) |
| `AZPANEL_VERSION` | конкретная версия, например `0.1.1` |

Пароль передаётся только переменной: флаг был бы виден в `ps` и в истории.

## Домен и HTTPS

Домен не обязателен. Внешний адрес панели — тот, что стоит в ссылках
портала и одноразовых ссылках (`panel.public_url`), — мастер ставит так:
задан домен — по домену, не задан — по внешнему IP сервера. Если домен
указывает на другой сервер, мастер предупредит об этом до подтверждения.
Адрес потом меняется на странице **Настройки**.

Сертификат при HTTPS мастер выбирает сам:

| Случай | Сертификат |
| --- | --- |
| по имени, в nginx есть ваш сайт | сертификат этого сайта |
| свой сайт azpanel (по порту или сайта нет), задан домен | уже выпущенный Let's Encrypt для домена, иначе новый |
| свой сайт azpanel, по IP | самоподписанный (браузер покажет предупреждение) |
| `AZPANEL_TLS=own` | ваш файл |

Для нового сертификата Let's Encrypt нужны домен, который указывает на этот
сервер, и порт 80; почта необязательна. Если на 80 уже работает nginx, проверка домена идёт
через него, остальные сайты не меняются. Продлевает certbot по своему
расписанию; после продления nginx перезагружается сам.

## Обновление и удаление

| Команда | Флаги |
| --- | --- |
| `update.sh` или `azpanel update` | `--check` — только проверить; `--yes` — без вопроса |
| `uninstall.sh` или `azpanel uninstall` | `--purge` — удалить и `/root/azpanel`; `--yes` — без подтверждения; `--skip-backup` — без бэкапа AntiZapret |

Флаги скриптам передаются после `--`:
`bash -c "$(curl -fsSL …/update.sh)" -- --check`.

Обновление проверяет подпись, делает бэкап, ставит новую версию, проверяет,
что службы поднялись, и откатывается при сбое. Удаление делает бэкап
AntiZapret и снимает только своё: службы, хук OpenVPN, фрагмент nginx.

## Пользователи и пароли в консоли

Команда `azpanel` без аргументов открывает меню: состояние, пользователи,
смена пароля, новый администратор, обновление, перезапуск служб. То же
скриптом `admin.sh`. Отдельные команды:

| Команда | Что делает |
| --- | --- |
| `azpanel user list` | пользователи панели |
| `azpanel user passwd <логин>` | задать свой пароль (спросит дважды, без вывода на экран) |
| `azpanel user passwd <логин> --generate` | сгенерировать пароль |
| `azpanel user add <логин>` | новый пользователь с ролью «пользователь», пароль сгенерировать |
| `azpanel user add <логин> --admin` | новый администратор |
| `azpanel user add <логин> [--admin] --password` | то же со своим паролем |

Сгенерированный пароль печатается один раз; при первом входе панель
потребует его сменить. Свой пароль — от 10 символов, с буквами и цифрами;
он нигде не печатается. Смена пароля завершает сессии пользователя и
выключает его двухфакторный вход. Логин — 3–32 знака: строчные латинские
буквы, цифры и `_ . -`.

В скрипте свой пароль передаётся через stdin двумя строками:
`printf '%s\n%s\n' "$PW" "$PW" | azpanel user passwd admin`.

## Файлы и службы

| Путь | Что |
| --- | --- |
| `/root/azpanel/bin/azpanel` | программа; ссылка `/usr/local/bin/azpanel` |
| `/usr/local/lib/azpanel/azpanel` | копия программы для хука OpenVPN: он работает не от root, а `/root` ему закрыт; обновляется сама при запуске агента |
| `/root/azpanel/etc/config.toml` | настройки (их же правит страница «Настройки») |
| `/root/azpanel/etc/secrets.env` | секреты, только root |
| `/root/azpanel/etc/install.env` | ответы мастера без секретов — подставляются при переустановке |
| `/root/azpanel/data/` | база панели, лимиты, история |
| `/root/azpanel/log/` | `node.log`, `panel.log` |
| `/root/azpanel/backup/azpanel/` | бэкапы перед обновлением панели |
| `/root/azpanel/backup/antizapret/archives/` | полные архивы AntiZapret: перед его обновлением и перед удалением панели |
| `/root/azpanel/backup/antizapret/lists/` | прежние версии списков маршрутизации и настроек AntiZapret |
| `/root/azpanel/backup/nginx/` | прежние версии конфигов nginx |
| `azpanel-node`, `azpanel-panel` | службы systemd |

Каталог — `/root/azpanel`, рядом с `/root/antizapret`, как у остальных
сервисов вокруг AntiZapret. Версии до 0.1.2 ставились в `/opt/azpanel`:
`update.sh` после обновления переносит такую установку сам, вручную —
`azpanel relocate`. При сбое перенос возвращает всё на место.

## FAQ

<details>
  <summary>Как открыть панель, установленную «только на 127.0.0.1»?</summary>

Через SSH-туннель с компьютера:

```bash
ssh -L 8080:127.0.0.1:8080 root@<сервер>
```

и откройте `http://127.0.0.1:8080/`.

</details>

<details>
  <summary>Как изменить адрес, порт или префикс панели?</summary>

Повторите мастер: `azpanel install`. Прежние ответы подставятся из
`install.env`, поменяйте нужные. `panel.base_path` и `panel.listen` можно
поменять и на странице **Настройки**: изменение применяется с таймером
возврата, если его не подтвердить.

</details>

<details>
  <summary>Панель не открывается снаружи</summary>

1. `azpanel doctor` покажет, что не так: службы, nginx, сертификат, диск.
2. На отдельном порту проверьте файрвол и правила облака: порт (8443 по
   умолчанию) должен быть открыт для входящих.
3. Проверьте **Настройки → Доступ**: при белом списке вход разрешён только с
   этих адресов.

</details>

<details>
  <summary>Браузер пишет, что сертификат недействителен</summary>

`azpanel doctor` покажет срок сертификата. Let's Encrypt не продлится, если
домен больше не указывает на этот сервер или порт 80 закрыт. При пути в
nginx сертификат принадлежит сайту nginx — продлевайте его там.

</details>

<details>
  <summary>Где журналы?</summary>

`/root/azpanel/log/node.log` и `panel.log`, а также `journalctl -u azpanel-node`
и `journalctl -u azpanel-panel`. Действия пользователей — в панели, раздел
**Журнал**.

</details>

<details>
  <summary>Команда azpanel не найдена</summary>

Ранние сборки (до 0.1.0) не ставили ссылку в PATH. Запускайте
`/root/azpanel/bin/azpanel` или создайте ссылку:
`ln -s /root/azpanel/bin/azpanel /usr/local/bin/azpanel`.

</details>

<details>
  <summary>Что azpanel меняет в системе?</summary>

Только своё: `/root/azpanel`, две службы, хук OpenVPN для лимитов, фрагмент
nginx (если выбран nginx) и сертификат (если выбран выпуск). Скрипты и
настройки AntiZapret меняются только вашими действиями в панели — теми же
скриптами AntiZapret.

</details>

## Безопасность

- Релизы подписаны ключом ed25519; `setup.sh` и `azpanel update` проверяют
  подпись и сумму до установки.
- Установщик AntiZapret-VPN запускается из `GubernievS/AntiZapret-VPN`
  (ветка `main`) так же, как в его README: этот шаг подписью azpanel не
  проверяется.
- Пароли хранятся хешами, вход защищён от перебора, есть двухфакторный вход и
  белый список адресов. Страницы отдаются со строгой CSP.
