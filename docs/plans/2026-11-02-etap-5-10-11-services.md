### Задача 1: версия AntiZapret

**Файлы:** `internal/antizapret/version.go`, агент — `GET
/v1/antizapret/version`, тесты.

- Источник: коммиты ветки `main` `GubernievS/AntiZapret-VPN` через
  GitHub API (публичный, без токена; 60 запросов в час — кеш на 1 час).
- Агент хранит коммит, с которого ставил (`data/antizapret.json`). Не
  ставил через панель — сравнивает SHA-1 git-blob своих скриптов
  (`up.sh`, `down.sh`, `parse.sh`, `update.sh`, `doall.sh`, `client.sh`)
  с деревом последних 200 коммитов; совпало — этот коммит; нет — «версия
  неизвестна, отличается от актуальной».
- Ответ: текущий коммит (или «неизвестно»), последний, список коммитов
  между (сообщение, дата).
- Тесты против поддельного GitHub API; хеш git-blob —
  `sha1("blob <len>\0" + data)`.

Коммит: «Агент: версия AntiZapret по коммитам репозитория».

### Задача 2: обновление AntiZapret

**Файлы:** `internal/node/azupdate.go`, `internal/antizapret/setupsh.go`,
тесты; панель — страница «Обновление AntiZapret».

- Проверки (отказ с причиной): свободно ≥ 2 ГБ в `/` и `/root`; нет
  `/var/run/reboot-required`; не запущены `apt`, `apt-get`, `dpkg`,
  `unattended-upgrade` (по `/proc/*/comm`).
- `client.sh 8`; бэкап копируется в `/root/backup-azpanel-<дата>.tar.gz`
  и в `/opt/azpanel/backup/`.
- Архив нужного коммита
  (`https://github.com/GubernievS/AntiZapret-VPN/archive/<sha>.tar.gz`)
  распаковывается во временный каталог; `setup.sh` оттуда — задачей, с
  переменными окружения из `setup` (все ключи, кроме `SETUP_DATE`) и
  `MTU` на стандартный ввод (первый вопрос — MTU — задаётся всегда).
- `setup.sh` сам перезагружает сервер. До запуска агент пишет
  `data/azupdate.json` (`{commit, started, backup, clients: [имена]}`).
- После загрузки агент видит `azupdate.json`: ставит хук, проверяет службы
  (OpenVPN по `*_ENABLE`, `kresd@*`, `wg-quick@*` при `WIREGUARD_ENABLE=y`),
  сверяет список клиентов с сохранённым; стоит AZ-WARP — `warper resync`;
  стоит telemt — его состояние. Итог — в `azupdate.json` (`ok` | `failed` +
  причины) и в API.
- Не прошло — панель показывает ошибку и кнопку «Восстановить из бэкапа»
  (`client.sh 9 <файл>` задачей).
- Ключи `setup` с применением `reinstall` (план этапа 3) — той же
  процедурой с изменёнными значениями; панель предупреждает о
  перезагрузке.
- Уведомления `antizapret_update` (новые коммиты, раз в сутки) и
  `update_result`.
- Тесты: проверки отказывают по каждой причине; окружение `setup.sh`
  содержит ключи и не содержит `SETUP_DATE`; MTU на stdin; после
  «перезагрузки» (новый экземпляр агента с `azupdate.json`) — итог
  посчитан; пропавший клиент — `failed`.

Коммит: «Обновление AntiZapret: проверки, бэкап, setup.sh, проверка после перезагрузки».

### Задача 4: WARP

**Файлы:** `internal/warp/` (`warper.go` — вызовы команд и разбор
`status json` с маскировкой; `install.go` — запуск `install.sh` AZ-WARP
под псевдотерминалом), агент — `/v1/warp/…`, панель — раздел «WARP»,
тесты.

- Встроенный WARP: режимы `ANTIZAPRET_WARP`, `VPN_WARP`, `DNS_WARP`,
  `WARP_MTU` — в «Настройках AntiZapret» (план этапа 3); здесь — сводка
  интерфейсов `warp-*` (`wg show`).
- AZ-WARP: обнаружение `/root/warper/version`; состояние — `warper status
  json`, поля `password` и всё, что содержит `key`, удаляются до передачи
  панели; обновление — `warper update`, затем `warper status json` и
  `warper doctor` в журнал задачи; домены — `domainslist`, `add`,
  `remove`, `domains save`, `enable|disable gemini|chatgpt`, `sync`;
  подсети — `iplist`, `ipadd`, `ipremove`, `ipsync`. `warper-web` не
  трогается.
- Установка: `install.sh` AZ-WARP читает ответы с `/dev/tty` — запуск под
  псевдотерминалом (`github.com/creack/pty`; проверь сборку с `go 1.24`);
  ответы из формы: режим (WARP / донор / WG / VLESS / Hysteria2 /
  OpenVPN) и данные, MTU, фейковая подсеть (`10.224.0.0/16`), списки
  Gemini и ChatGPT. Известные вопросы — таблица «образец строки → ответ»;
  неизвестный — остановка с выводом в журнал, не отвечать наугад. Тексты
  вопросов — по `install.sh` `Liafanx/AZ-WARP` (копия будет в `testdata/`).
- Тесты: маскировка секретов в `status json` (образец с 94 с заменёнными
  значениями); диалог установщика по записанному сценарию; неизвестный
  вопрос — остановка.

Коммит: «WARP: встроенный и AZ-WARP — состояние, установка, обновление, домены».
